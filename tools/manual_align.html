타임 셔틀 - 수동 정렬 도구

사용 방법:

  1. 아래에서 정렬할 트랙 쌍을 선택하세요.
  2. 원곡을 재생하여 뚜렷한 가사/후렴 시작 지점에서 일시정지하고 "이 지점 마크"를 누릅니다.
  3. 리메이크를 재생하여 동일한 가사/후렴 시작 지점에서 일시정지하고 "이 지점 마크"를 누릅니다. (방향키 ← → 로 미세조정 가능)
  4. 하단에서 자동으로 계산된 Offset을 확인하고, "테스트 셔틀 재생"으로 자연스럽게 넘어가는지 테스트합니다.
  5. 모든 곡에 대해 반복한 뒤 최하단의 코드를 js/align.js에 복사해 붙여넣으세요.
